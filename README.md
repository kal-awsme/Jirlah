# schedule flow by VELLORA

Mobile-first personal organizer built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive Ice Glass interface and CSS-generated visual identity
- `app.js` — folders, tasks, filters, calendar, progress, focus timer, settings, and LocalStorage

No image asset folder is required. Visuals are CSS-generated. Google Fonts are optional; system fonts are fallback.

## GitHub Pages
Upload all four files directly to the repository root. Then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. Open the Pages URL once deployment finishes.

## Notes
Workspace data is stored in LocalStorage. Custom photos are resized and saved in the browser. Browser notifications require permission and may vary by browser. This is the web-preview package; an installable offline PWA needs a manifest and service worker in a later stage.
